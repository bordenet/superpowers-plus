# CI bats policy -- consumed by tools/ci-bats-discovery.sh
#
# Every .bats file under test/, tests/ and skills/ runs in CI automatically.
# This file is ONLY for suites that need special handling. Format:
#
#   exclude <path>            <reason...>     suite is not run at all
#   env     <path> KEY=VALUE  <reason...>     suite runs with KEY set
#
# $REPO_ROOT in an env VALUE expands to the repo root. Nothing is eval'd.
# `ci-bats-discovery.sh --lint` enforces these rules:
#   - <path> must exactly match a suite printed by --list (no ./ or .. aliases)
#   - only exclude and env directives are accepted; env takes one allowlisted
#     UPPER_SNAKE=VALUE assignment (a second such token is rejected)
#   - every entry needs a reason; ordinary prose such as issue=https://... is OK
#   - each suite path may appear only once across all directives

env tests/augment-non-regression-test.bats PERSONAL_SKILLS_DIR=$REPO_ROOT/skills  suite resolves the skills tree from this env var, not from cwd
