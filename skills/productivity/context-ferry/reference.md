# Context Ferry reference

## Trigger mechanics

The UserPromptSubmit hook warns once near 70% of the configured context window using the newest transcript usage object. When usage is unavailable it degrades to a raw-turn threshold. Its per-session flag prevents repeated warnings.

The PreCompact hook is a backstop near compaction. It creates a scaffold with branch, recent commits, worktree state, unpushed commits, and a guidance excerpt, leaving only conversation-specific decisions/questions/actions for the model to append. Platforms without hooks require manual invocation.

## Output template

```text
  ## CONTEXT FERRY -- <ISO date> <HH:MM UTC>
Generated by context-ferry. Paste into a fresh session to resume.
Fidelity: <signal from the fidelity section>

  ### Original Goal
<One to three sentences: objective and why it matters.>

  ### Pending Questions for You
Re-ask before other work:
1. "<exact unanswered question>"
<Omit when none are pending.>

  ### Pending / Queued Tasks
Source: <task file path or conversation memory>
- [ ] <unstarted task>
<Omit when empty.>

  ### Key Decisions Made
- <decision, rejected alternative, and reason>
- <user clarification or authority boundary>

  ### Execution Document
Current as of this ferry: `<absolute plan/checklist path>`
<Omit when none exists.>

  ### In Progress / Blocked
- In progress: <partial state>
- Blocked: <cause and needed action>

  ### Next 3 Actions
1. <If a question is pending, re-ask question 1.>
2. <next action>
3. <next action>

  ### Key Files & Diffs
- `path/to/file` -- <purpose and current state>
```

## Fidelity and sensitive content

Choose the fidelity signal from estimated remaining context:

| Remaining | Signal |
|---|---|
| More than 20% | `high (generated proactively -- full fidelity)` |
| 10-20% | `moderate (generated under context pressure -- verify specifics)` |
| Less than 10% | `degraded (generated at critical low context -- verify Key Files with git/file reads)` |

At every fidelity, trust the captured goal, verbatim questions, and authoritative task source. At degraded fidelity, verify decisions against repository evidence and run `git status` before trusting file-state claims.

If the session may include credentials, tokens, API keys, PII, or private/internal URLs, prepend:

```text
Warning: this session may contain sensitive content.
Review ~/context-ferry-<timestamp>.md before sharing it.
```

Do not block or skip generation. The user controls later storage and sharing.

## Failure modes

| Failure | Recovery |
|---|---|
| Compaction interrupts generation | Save or print completed blocks; Partial ferry is better than no ferry. |
| No execution document | Put all task/progress state inline and omit that section. |
| Pending issue was implicit | State it as a direct question and label it as rephrased. |
| Task file unreadable | Name the unreadable path and fall back to memory-labeled tasks. |
| No Git repository | Record that fact and continue. |
| Write tool unavailable | Print the ferry prompt and ask the user to save it. |
| Early warning ignored | Rely on the PreCompact scaffold, but mark fidelity degraded if needed. |

## Companion skills

- `session-handoff`: cold-start sibling Git activity.
- `todo-management`: authoritative task source.
- `branch-sync-gate`: resume an existing shared branch.
- `think-twice`: escape a reasoning loop before ferrying.
