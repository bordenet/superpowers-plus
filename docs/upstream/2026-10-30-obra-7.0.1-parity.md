# obra/superpowers 7.0.1 parity and uninstall — October 30, 2026

Goal: superpowers-plus covers everything the obra plugin provides, so the
plugin can be removed from both hosts.

**Source version: obra/superpowers v7.0.1, commit
`2ce8aa15d05bd57213e6f746f953aafb7ded7a8b`.** As of 2026-10-30 this is the
latest GitHub release and also the `main` tip. Every port below comes from
that version only. The upstream tarball's `skills/` and `hooks/` were verified
byte-identical to the Codex cache this work read. Older installed copies
(Claude Code plugin 4.0.3, the v6.3.0 staging checkout) were used only to
inventory the Claude Code commands and agent, which v7.0.1 no longer ships.
Earlier v6.x ports (e.g. brainstorming's v6.3.0 router) were checked against
v7.0.1 and updated, not kept alongside. The previous review was
[2026-10-01](2026-10-01-obra-review.md) (v6.4.2).

Status key: **Covered** = already equivalent or a superset before this
change. **Closed** = was partial or missing; this change closes it.

## Decision: requests that are already complete

obra 7.0.1 does a fully specified request directly. superpowers-plus said
"the approval gate never scales". **Adopted obra's behavior as a narrow Clear
path.** An approval round on a request that already fixes every material
choice asks the user to repeat what they just said. It costs a turn and adds
no information, and the gate exists to stop building the wrong thing, which
cannot happen when nothing is left to interpret. The test is falsifiable:
if you can name one open choice that would change the result, the request is
not Clear. A request that asks to brainstorm is never Clear. Every other
path keeps the gate.

## Token impact

`claude plugin details superpowers@superpowers-marketplace` projects the
plugin at about 1,168 always-on tokens per session for its skill listings and
`code-reviewer` agent.
Its SessionStart hook also injects the full 4.0.3 `using-superpowers`
`SKILL.md` (3,798 bytes, roughly 950 tokens) on startup and again after each
clear or compaction. So removal saves roughly 2,100 tokens per session plus
about 950 per compaction. Added resident cost: the one SessionStart line
(about 60 tokens). Every skill changed here is either user-only
(`disable-model-invocation: true`, no resident cost) or was already listed,
and is loaded only when invoked.

## Uninstall obra (Matt runs these)

Order matters: deploy this change and prove it landed before the plugin goes
away.

1. Deploy superpowers-plus from up-to-date `main`:

   ```bash
   cd ~/git/Personal/superpowers-plus && git switch main && git pull --ff-only && ./install.sh --yes
   ```

2. Gate: the deploy contains this change (expect `deploy OK`; anything else
   means stop and do not uninstall):

   ```bash
   test -x ~/.claude/hooks/session-start-skill-resolution.sh && test -f ~/.claude/skills/sp-brainstorm/builder-check-prompt.md && ! test -e ~/.claude/skills/sp-brainstorm/spec-document-reviewer-prompt.md && test -f ~/.codex/skills/executing-plans/scripts/task-start && grep -q session-start-skill-resolution ~/.claude/settings.json && echo 'deploy OK'
   ```

3. Claude Code:

   ```bash
   claude plugin uninstall superpowers@superpowers-marketplace
   ```

   ```bash
   claude plugin marketplace remove superpowers-marketplace
   ```

   Then delete the `"superpowers@superpowers-marketplace": true` line under
   `enabledPlugins` in `~/.claude/settings.json` if the uninstall left it.

4. Codex. Back up the config first:

   ```bash
   cp -p ~/.codex/config.toml ~/.codex/config.toml.bak-pre-obra-uninstall
   ```

   ```bash
   codex plugin remove superpowers@superpowers-marketplace
   ```

   ```bash
   codex plugin marketplace remove superpowers-marketplace
   ```

   If either command leaves config behind, delete these blocks from
   `~/.codex/config.toml` by hand:

   ```toml
   [marketplaces.superpowers-marketplace]
   last_updated = "…"
   last_revision = "…"
   source_type = "git"
   source = "https://github.com/obra/superpowers-marketplace.git"

   [plugins."superpowers@superpowers-marketplace"]
   enabled = true
   ```

## Rollback

Rollback installs the marketplace's current release, not the removed 4.0.3
(Claude Code install was `gitCommitSha` `b9e16498b9b6b06defa34cf0d6d345cd2c13ad31`).
In order:

```bash
claude plugin marketplace add obra/superpowers-marketplace
```

```bash
claude plugin install superpowers@superpowers-marketplace
```

```bash
codex plugin marketplace add https://github.com/obra/superpowers-marketplace.git
```

```bash
codex plugin add superpowers@superpowers-marketplace
```

Compare against the backup rather than overwriting it, so later Codex edits
survive. Only the marketplace `last_updated`/`last_revision` lines should
differ; restore any other differing setting by hand:

```bash
diff ~/.codex/config.toml ~/.codex/config.toml.bak-pre-obra-uninstall
```
